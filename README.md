### 🏗️ Flagship Project — S.C.O.P.E.

**Secure Cognitive Online Proctoring Ecosystem**

A distributed, proctored exam platform combining Aptitude MCQs, Technical MCQs, and live coding — built to survive real exam-day traffic, not just pass a demo.

- Distributed grading engine: Nginx load balancer + Redis job queue routing code payloads across isolated Judge0 Docker nodes, supporting 8 languages (Java, Python, C++, C, JavaScript, C#, Go, SQL)
- In-browser Monaco IDE with server-synced timers, anti-navigation guards, and "best attempt" scoring protection
- Live Test Monitor for admins: real-time leaderboard, coding telemetry, and WebSocket-broadcast time extensions
- **Load tested with k6: 446,340 requests at 1,487 RPS with 0.00% failure rate**, optimized to safely support 6,000–7,500 concurrent users
- **Adopted by TCET** for institutional placement drives, replacing manual grading with automated evaluation

`React 19` `Node.js` `Express 5` `Prisma` `PostgreSQL` `Docker` `Nginx` `Redis` `Judge0` `Socket.IO`
