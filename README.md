## 🏗️ Flagship Project — S.C.O.P.E.

**Secure Cognitive Online Proctoring Ecosystem**

A distributed online assessment platform built to survive real exam-day traffic, not just pass a demo.

- Architected an Nginx gateway load-balancing traffic across isolated Docker-based Judge0 nodes for secure, sandboxed code execution
- Engineered an async Redis queue processing **446,340 requests at 1,487 RPS with 0% failure rate** under DoS-style load testing
- Scaled to support **7,500 concurrent users**, with real-time analytics for exam administrators
- **Adopted by TCET** for institutional placement drives, replacing manual grading with automated evaluation

`React` `Node.js` `PostgreSQL` `Docker` `Nginx` `Redis` `Judge0`
